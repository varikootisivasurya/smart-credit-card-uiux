# Smart Credit Card Recommender Platform – UI/UX

A mobile-first UI/UX design that helps users discover the best credit cards
based on their spending habits, lifestyle, and credit profile.

---

## 🎯 Project Goal
To simplify credit card selection by providing clear recommendations,
transparent rewards estimation, and easy comparison in a clean, modern UI.

---

## 🧠 UX Principles Followed
- Simple & clean interface
- Mobile-first responsive design
- Minimal steps to recommendations
- Visual comparison & savings clarity
- Trust-building through transparency

---

## 🖥️ Key Screens

### 1. Landing Page
Introduces the platform, builds trust, and guides users to start the journey.

![Landing](screens/landing.png)

---

### 2. User Onboarding / Lifestyle Form
Collects spending and credit details using sliders, dropdowns,
and a step-by-step flow to reduce friction.

![Onboarding](screens/onboarding.png)

---

### 3. Card Recommendation Results
Displays best-match credit cards with filters, savings estimation,
approval chance, and quick actions like apply or compare.

![Results](screens/card-recommendation-results.png)

---

### 4. Card Comparison
Allows users to compare multiple cards side-by-side to make
confident financial decisions.

![Comparison](screens/comparison.png)

---

### 5. Smart Alerts Dashboard
Notifies users about better cards, upcoming fees, and important updates.

![Alerts](screens/alerts.png)
